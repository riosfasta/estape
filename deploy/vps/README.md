# Debian VPS Deployment

These scripts set up bugmega on a Debian VPS with:

- Go installed from the official Linux tarball
- MongoDB Community installed from the official MongoDB apt repository
- A systemd service named `bugmega`
- nginx as a reverse proxy
- GitHub pull-based updates
- MongoDB and uploads backup/restore helpers

The defaults target **Debian 12 Bookworm** and **MongoDB 8.0**.

## Scripts

| Script | Purpose |
| --- | --- |
| `env.example` | Copy this to `/etc/bugmega/deploy.env` and edit real values. |
| `setup-debian.sh` | First-time VPS bootstrap: packages, Go, MongoDB, nginx, service, deploy. |
| `deploy.sh` | Repeatable update: `git pull`, build Go binary, write env, restart service. |
| `backup-mongodb.sh` | Creates MongoDB and uploads backups. |
| `restore-mongodb.sh` | Restores MongoDB and optionally uploads after typing `Confirm`. |

## First Setup

1. Push this repository to GitHub.

2. SSH into the VPS, then install Git:

```bash
sudo apt-get update
sudo apt-get install -y git ca-certificates curl
```

3. Clone the repo:

```bash
sudo mkdir -p /opt/bugmega
sudo git clone https://github.com/YOUR_USER/YOUR_REPO.git /opt/bugmega/app
```

For a private repo, add a deploy key to the VPS first, then use the SSH URL:

```bash
sudo git clone git@github.com:YOUR_USER/YOUR_REPO.git /opt/bugmega/app
```

4. Create the server config:

```bash
sudo mkdir -p /etc/bugmega
sudo cp /opt/bugmega/app/deploy/vps/env.example /etc/bugmega/deploy.env
sudo nano /etc/bugmega/deploy.env
```

At minimum update:

```text
APP_DOMAIN=yourdomain.com
APP_URL=https://yourdomain.com
REPO_URL=https://github.com/YOUR_USER/YOUR_REPO.git
OWNER_EMAIL=you@yourdomain.com
OWNER_PASSWORD=a-long-safe-password
JWT_SECRET=
```

Leave `JWT_SECRET` blank if you want the script to generate one.

5. Run setup:

```bash
sudo bash /opt/bugmega/app/deploy/vps/setup-debian.sh
```

6. Check the service:

```bash
sudo systemctl status bugmega
curl -I http://127.0.0.1:8080
```

## Updating From GitHub

After pushing changes to GitHub:

```bash
sudo bash /opt/bugmega/app/deploy/vps/deploy.sh
```

That command pulls the configured branch, builds `./cmd/server`, and restarts systemd.

## TLS / HTTPS

If the domain DNS already points to the VPS, set these before first setup:

```text
ENABLE_CERTBOT=true
CERTBOT_EMAIL=you@yourdomain.com
```

Then `setup-debian.sh` will install certbot and request an nginx certificate.

If you enable TLS later:

```bash
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com --redirect
```

## Backups

Create a backup:

```bash
sudo bash /opt/bugmega/app/deploy/vps/backup-mongodb.sh
```

Restore a backup:

```bash
sudo bash /opt/bugmega/app/deploy/vps/restore-mongodb.sh \
  /var/backups/bugmega/bugmarking-YYYYMMDD-HHMMSS.archive.gz \
  /var/backups/bugmega/uploads-YYYYMMDD-HHMMSS.tar.gz
```

## Important Paths

| Path | Purpose |
| --- | --- |
| `/opt/bugmega/app` | Git checkout. |
| `/opt/bugmega/bin/bugmega` | Built Go binary. |
| `/etc/bugmega/deploy.env` | Deployment config and secrets. |
| `/etc/bugmega/bugmega.env` | systemd environment file generated by `deploy.sh`. |
| `/var/lib/bugmega/uploads` | Uploaded files. |
| `/var/backups/bugmega` | Backups. |
| `/etc/systemd/system/bugmega.service` | systemd service. |
| `/etc/nginx/sites-available/bugmega.conf` | nginx proxy config. |
